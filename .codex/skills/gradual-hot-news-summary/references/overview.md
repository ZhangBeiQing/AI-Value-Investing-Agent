# 渐进式新闻总结概览

## 目标

这个能力不是做“今日新闻摘要”，而是维护一个可被后续本地选股 agent 直接继承的“主题级研究记忆”。

它解决的问题是：

1. 昨天市场在交易哪些主题
2. 今天新增新闻让哪些主题被强化、弱化、证伪或切换
3. 哪些主题已经被板块资金确认，哪些只是文字层噪声
4. 哪些主题值得驱动 agent 去股票宇宙外补搜索新的标的
5. 如何把这些叙事级上下文交给明天才上线的全新 agent

## 在整个系统中的位置

- `macro_summary`：世界观 / 大类资产框架
- `gradual_hot_news_summary`：可交易叙事的演化记忆
- `board_heat_state`：板块与资金确认
- `stock_snapshot_payload`：个股事实层与估值层

一句话：

- 宏观总结回答“为什么世界在变化”
- 渐进式新闻总结回答“今天该重点交易什么叙事”
- 板块热点回答“市场到底有没有在交易这个叙事”
- snapshot 回答“具体买哪只股票”

## 和其它模块的边界

### 宏观总结

宏观总结提供顶层 regime。

渐进式新闻总结不重写宏观总结，但必须读取最近一天宏观总结，把新闻放进正确的宏观背景中理解。

### 板块热点

板块热点提供盘面验证。

渐进式新闻总结不替代板块热度层，但必须读取最近一天板块热点状态，判断主题是否被市场真实交易。

### 个股 snapshot

个股 snapshot 提供估值、质量、财报、经营和风险。

渐进式新闻总结不做最终选股结论，只负责把 agent 的注意力引导到值得研究的主题和股票候选。
