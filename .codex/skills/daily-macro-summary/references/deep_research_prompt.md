# Deep Research Prompt

仅在**基线重建**时使用：`data/macro_economy/` 为空、最近文件超过 7 天，或宏观 regime 明显切换。
输出结构直接遵循 [report_contract.md](report_contract.md)，不另行定义。

```text
请针对最近 6-8 周的全球与中国宏观信息做一次高信噪比深度研究，用于生成一个“可日更维护”的宏观基线文档，而不是一次性长篇报告。

目标不是搜集越多越好，而是提炼未来 1-2 周最影响 A 股 / 港股 / 黄金 / 石油 / 美股定价的宏观锚点。

原则：
1. 只保留对资产定价有持续影响的信息，删除冗余背景和重复新闻。
2. 中国部分必须同时写：发生了什么 / 官方怎么定调 / 主流机构如何解读政策力度。
3. 宏观数据优先给出公布值 vs 预期值，前值仅在判断趋势必需时补充；缺失值不得编造。
4. 持续性风险最多选 3 个，每个一个短段：必要背景、最新进展与当前状态、资产传导；不固定写五段，不保留完整历史节点链。
5. 无重大更新的低优先级事项直接省略，不逐项写 N/A；研究清单不等于正文展示清单。
6. 完整文件以 1500-2000 字为宜，能更短讲清就不扩写；重大事件日可扩至 2500 字，硬上限 3000 个非空白字符（含标题、表格、数字、英文和标点）。研究笔记不并入正文。

7. 读者是固定股池主 Agent 与逐股辩论角色。只提供公共宏观事实、变化、传导条件与不确定性，行业景气、公司经营和估值留给股票研究角色，不预设个股动作。
8. AI/科技只保留影响整体估值、融资条件或风险偏好的信息；不写产业链研究或逐股新闻。下游会追加客观面板与上证指数分析，正文不复制完整面板或技术指标。

研究核查范围（正文按报告契约筛选，不要求逐项展示）：
一、市场价格与利率锚：US10Y、US02Y、DXY、USD/CNH、中国 10Y、COMEX 黄金、Brent / WTI
二、全球央行与流动性：Fed（利率、纪要、票委表态、下次会议预期）、PBOC（LPR、MLF、逆回购、稳汇率与信贷口径）、BOJ、ECB
三、中国政策与官方定调：政治局会议、国常会、中央财经委、深改委；发改委、财政部、证监会、金融监管总局、央行；人民日报、新华社、求是的高权重评论
四、中国与美国核心数据 surprise：中国 CPI、PPI、社融、M1/M2、PMI、出口；美国 CPI、PCE、非农、零售销售
五、持续性风险：中东/红海/伊朗-以色列、俄乌、中美关税与出口管制、中国地产与地方债

请只按报告契约的五节结构输出，不额外增加开头锚点列表、附录或长版。
研究优先核验官方与高质量机构资料；最终正文保留必要日期与结论，不展示引用或来源清单。
落盘后按契约统计完整文件的非空白字符数，超过 3000 必须压缩并重新统计后才交付。
```
