# Report Contract

推荐输出结构：

## 1. 今日变化摘要

- 只写相对上一份宏观总结的新增变化
- 若无实质新增，直接写：
  - `今日无实质宏观增量，沿用上一份宏观框架；但以下正文仍保留当前有效的宏观状态快照。`

重要约束：

- `今日变化摘要` 只负责说明今天相对昨天“变了什么 / 没变什么”，不能替代整份报告
- 即使今天没有新增新闻，今日文件也必须继续保留当前仍有效的：
  - 市场与利率面板
  - 央行与流动性状态
  - 最近仍有效的宏观数据锚点
  - 仍然有效的中国政策信号
  - 仍需跟踪的持续性风险状态
- 目标是让一个全新的 Agent 只读今天这份文件，也能恢复当前宏观框架，而不是必须倒回昨天文件补上下文

## 2. 市场与利率面板

用表格，字段尽量固定：

| 类别 | 指标 | 最新值 | 前值/预期 | 变化 | 解释 |
| :--- | :--- | :--- | :--- | :--- | :--- |

建议至少覆盖：

- US10Y / US02Y
- DXY
- USD/CNH
- COMEX黄金
- Brent / WTI
- 中国 10Y 国债

## 3. 央行与流动性

按“事实 + 市场预期 + 资产映射”写：

- Fed
- PBOC
- BOJ
- ECB

每个央行最多 3 条：

1. 最新动作/表态
2. 市场主流预期是否变化
3. 对美元、利率、A/H 股、黄金的影响

## 4. 宏观数据惊喜卡

只保留最近两周内最重要的数据 surprise；但若更早的数据仍然是当前宏观判断的关键锚点，也允许继续保留：

| 地区 | 数据 | 公布值 | 预期值 | 前值 | 结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |

优先级：

- 中国：CPI、PPI、社融、PMI、出口
- 美国：CPI、PCE、非农、零售销售

## 5. 中国政策信号卡

只保留仍对市场有影响的政策：

| 政策/会议 | 日期 | 核心内容 | 官方定调 | 市场/机构解读 | 影响板块 |
| :--- | :--- | :--- | :--- | :--- | :--- |

不要重复旧会议的长篇背景，只保留当下仍有效的政策信号。

## 6. 持续性风险跟踪

只跟踪少数仍有交易意义的事项：

- 中东 / 伊朗-以色列
- 俄乌
- 中美关税 / 出口管制
- 中国地产 / 地方债

这一节默认是给“明天新开的 AI”读的，所以要做到**不看昨天文件也能恢复上下文**。

每项至少写 5 段固定信息，保持短但自解释：

1. **最小背景**：谁和谁之间的什么风险，为什么它会进入当前资产定价
2. **关键节点链**：从事件启动以来，只保留 2-4 个仍然影响当前市场判断的重要节点，尽量带日期
3. **最近几天最新进展**：重点写最近 1-3 天；若无新增，也明确写“最近几天无实质新增”
4. **当前状态判断**：升级 / 缓和 / 僵持 / 已消化，但必须写清楚是在什么维度上
5. **资产与政策传导链**：它如何影响油价 / 航运 / 避险资产 / 科技链 / 国内信用 / 利率预期 / 央行路径

写作约束：

- 禁止只写“升级”“僵持”而不说明到底在升级什么
- 禁止出现让陌生读者无法指代解析的写法，例如“该冲突”“该风险”“这一局势”却没有前文定义
- 不要求逐日流水账；若事件已持续多日，早期只保留关键节点，最近几天写得更具体
- 必须让第一次读今天文件的 Agent 能理解后文为什么会提 Fed、油价、黄金、出口链或相关股票板块

## 7. 资产映射

固定给出 4 句话：

- **A股**：
- **港股**：
- **黄金**：
- **石油**：
- **美股**：

要求：

- 必须是可执行的市场理解，不要空话
- 例如“利率与美元共振压制黄金短线，但若地缘升级重新发酵，黄金仍有反抽条件”

## 8. 未来几天关注事项

每天都必须写这一节，作为下一天继续更新的搜索锚点。

建议表格：

| 日期/时间窗口 | 事件 | 为什么重要 | 可能影响的资产/板块 | 明日更新时优先搜索什么 |
| :--- | :--- | :--- | :--- | :--- |

典型事项：

- 美联储议息会议 / 会议纪要 / 主席或票委讲话
- 中国两会 / 政治局会议 / 国常会 / 央行操作窗口
- 美国 CPI / PCE / 非农 / 零售销售
- 中国 CPI / PPI / 社融 / PMI / 出口
- 日本央行 / 欧洲央行会议
- 持续性战争、油价、航运、关税、出口管制的后续变化

写作要求：

- 尽量给具体日期，若日期未确定则给时间窗口
- 不要只写事件名，必须写“为什么要盯”
- 这一节是给“明天的 Agent”用的，必须足够直接，便于第二天继续搜索与比对
