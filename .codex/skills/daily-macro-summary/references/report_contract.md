# Report Contract

本文件是宏观总结的输出结构、篇幅与写作细节的唯一权威来源。日常增量、事件加强搜索与基线重建均适用。

## 篇幅与取舍（最高优先级）

- 以 **1500-2000 字**为宜，能更短讲清就不扩写，不设最低字数；重大事件日可扩至 2500 字；**硬上限 3000 字**。
- “字数”按完整 Markdown 文件的**非空白字符数**统计，标题、数字、英文、标点、表格和 Markdown 标记全部计入；不以汉字数、字节数或 token 数替代。
- 各节预算只供规划，不必凑满；总上限优先于覆盖广度、背景展开与旧稿继承。重大事件日与基线重建不豁免。
- 新 Agent 只读当天文件，应能理解最重要的宏观主线；不要求恢复全部历史。旧稿作为输入，失效和低优先级信息直接删除，不逐日累加。
- 同一事实与数字只展开一次；禁止用附录、长版、新闻流水账、逐股涨跌名单或研究笔记绕过限制。
- 研究时核查 skill 所列全部必需指标，正文只筛选最影响未来 1-2 周定价的信息；核查清单不等于正文展示清单。

## 下游用途与研究边界

- 服务 fixed_tracked 主 Agent 的系统风险与市场风格判断，以及 Bull、Bear、Juror 和 finalizer 的逐股论证与审查。各角色完整阅读公共上下文，正文应简洁、可核验，并为独立推理保留空间。
- 集中回答：当前宏观环境是什么、今天改变了什么、通过哪些共同渠道影响资产、接下来什么事实会改变判断。
- 保留中国增长与政策、流动性、海外利率、美元与人民币、能源与地缘、整体风险偏好；传导聚焦折现率、总需求、融资条件、汇率和成本。
- 行业订单、排产、产品价格与供需、竞争格局、公司业绩和估值留给股票研究角色，不在宏观稿中展开。行业政策仅在具有跨行业或系统影响时提炼宏观含义。
- 美股科技或 AI 信息只在影响整体科技估值、融资条件或风险偏好时简写，不展开公司财务、产业链景气或个股名单。
- 明确事实、分析推断、关键条件及不确定性，不替各角色指定个股方向、数量、目标价或仓位。
- 下游 `01_global_context.md` 还会自动追加客观数据面板和上证指数分析。正文只保留支撑宏观主线的紧凑价格锚，不复制完整客观面板、采集日志或上证技术指标；字数上限针对本 skill 的最终文件，不代表整个 `01_global_context.md` 的长度。

## 输出结构

标题注明分析日，头部一行注明数据截止时点。正文保留以下五节，顺序固定，标题不带编号，不另增摘要或宏观锚点章节。

### 今日变化

预算约 200-250 字，最多 3 条。每条写“新增事实 → 判断是否改变”，不重复后文数字与完整背景。无实质增量时一句话说明，后续仍提供精简状态快照。

### 市场与利率面板

预算约 250-300 字，使用紧凑表格：

| 指标 | 最新值（日期） | 日变动或关键说明 |
| :--- | :--- | :--- |

覆盖 US10Y / US02Y、DXY、USD/CNH、COMEX 黄金、Brent / WTI、中国 10Y；同类可合并一行，不额外堆指标。共同日期在表前统一注明，仅单独标注不同日期。无新值简注“沿用”，未核实写“待核验”，不得填估测值；传导解释放后文，不逐行展开。

### 政策与数据

预算约 500-600 字，最多 8 条紧凑条目，不使用七列长表。

- Fed、PBOC、BOJ、ECB 各最多一条，交代当前利率或政策状态、关键变化与定价含义；BOJ、ECB 无重要变化时可合并一条。
- 中国政策与中美核心数据合计最多 4 条，只选关键政策和数据 surprise；较早数据仅保留当前判断必需的锚点。
- 数据优先写“公布值 vs 预期值”，仅在判断趋势必需时补前值；预期缺失不得编造。
- 用“官方：……；判断：……”区分定调与推断，不展开背景长段。
- 美股最新交易时段、主要指数表现与风格变化压为 1-2 句，可放本节，不展开逐股新闻。

### 持续性风险

预算约 300-400 字，最多 3 个关键风险。每个只写一个短段：必要背景、最新进展与当前状态、资产传导；必要时带一个关键日期。

不再要求每个风险固定五段或完整节点链。已消化、重复、无变化且影响较弱的风险可删除；无关键风险时一句话说明。说清升级或缓和的具体维度；未经证实的线索明确标注不确定性，不用空泛结果词替代事实。

### 资产映射与明日关注

预算约 200-300 字。

**资产映射**：A 股 / 港股 / 黄金 / 石油 / 美股各一句短判断，写主要驱动或判断改变的条件，不重复背景与面板数字，不输出具体交易指令。

**未来几天关注事项**：最多 3 条，用“日期或时间窗口｜事件｜影响及下一次优先核验点”表达，合并重要性与搜索锚点，不使用五列长表。日期不确定时明确写时间窗口，不猜测。

## 最终验收

1. 核对日期、事实、沿用值、推断与不确定性。最终正文不得含原始 URL、Markdown 链接、脚注、括号来源引用或独立来源清单。
2. 对实际落盘文件统计完整非空白字符数（路径替换为分析日）：

   ```bash
   python -c "from pathlib import Path; s=Path('data/macro_economy/YYYYMMDD.md').read_text(encoding='utf-8'); n=sum(not c.isspace() for c in s); print(n); assert n <= 3000, f'宏观总结超限：{n}/3000'"
   ```

3. 超限必须编辑压缩后重新统计。优先删重复解释、低优先级数据与历史节点，再缩短句子；保留关键事实及不确定性。不得生硬截断或仅声称“已尽量精简”便交付。
