# Daily Macro Summary

## 何时使用

- 用户要更新当天宏观总结，或生成 `data/macro_economy/YYYYMMDD.md`
- 要产出“可日更维护的状态快照 + 今日增量”，而不是一次性长篇宏观研报

## 日期与路径

- 所有路径、文件名、正文日期都遵循 `AGENTS.md` 的 `--date` 口径：**要分析的交易日**。用户指定则用指定日期，否则用 today。
- 输出：`data/macro_economy/YYYYMMDD.md`
- 数据面板：`data/global_cache/macro_objective_panel/daily_snapshots/YYYY-MM-DD.json`，缺失时回退 `latest.json`

## 执行流程

### 1. 读输入（按顺序）

1. **宏观客观数据面板**（硬数据主源）：当日快照 → `latest.json` → 都没有时才自行联网抓硬数据
2. **最近一份宏观总结**：`data/macro_economy/` 下日期 ≤ 今日的最近文件，**必须从头到尾完整读完**，禁止只用 `rg` 或局部摘录
3. 若该文件距今天超过 7 天，再额外参考最近一次高质量基线文件

### 2. 选模式

| 模式 | 触发 | 做法 |
| :--- | :--- | :--- |
| **日常增量**（默认） | `data/macro_economy/` 有 7 天内的文件 | 刷硬数据 + 搜当日增量，无实质新增则沿用核心判断 |
| **基线重建** | 目录为空 / 最近文件超 7 天 / regime 明显切换（央行重大转向、战争与关税质变、中国会议改口径） | 参考 [deep_research_prompt.md](references/deep_research_prompt.md) 做深度搜索，重写高信噪比基线 |

日常增量遇到以下情况时按“事件级”加重搜索力度（仍属日常增量，不必进入基线重建）：
中国 CPI/PPI/社融/PMI/出口、美国 CPI/PCE/非农/零售/FOMC、央行刚开完会或核心官员密集讲话、金价油价美债美元异常波动、持续性风险出现方向性变化。

### 3. 写文件

- **篇幅优先**：以 1500-2000 字为宜，能更短讲清就不扩写；重大事件日可扩至 2500 字，硬上限 3000 字。日常增量、事件加强搜索与基线重建均适用，统计口径与分节预算以 `references/report_contract.md` 为准。
- 旧稿只作为判断输入，不要求逐段继承。先筛选当前最重要的信息，再生成当天快照；删除重复、失效与低优先级背景，禁止逐日追加导致篇幅累积。
- **当日文件已存在**：先 `cp` 备份为 `.md.bak`；合规短稿可定点更新，过长或冗余的旧稿允许整体重写压缩。核对事实、日期与字数后删除 `.bak`。
- **当日文件不存在**：参考上一份判断写精简快照，不直接复制长稿追加；更新标题日期、数据口径与今日变化。
- **基线重建**：允许全量重写，研究笔记不并入正文，仍受 3000 字上限约束。
- **落盘验收**：统计完整文件的非空白字符数，超过 3000 必须压缩后重新统计，合格才交付。

### 4. 搜索

1. 先消费面板里的硬数据，**不绕过 shared_data_access 重抓面板已有指标**——除非面板缺失或状态为 `warning` / `stale`
2. 搜索入口遵循 `configs/research/web_research_policy.md`：Codex + GPT 优先自带搜索，其他组合优先百炼 MCP；需要多轮交叉验证才升级到 deep search；**只有基线重建才用 deep research**
3. **每日必搜美股**，不得跳过：按当前北京时间判断拉取哪个时段（06:00–20:00 前一交易日收盘 + 盘前期货；20:00–21:30 盘前；21:30–次日 04:00 盘中；04:00–06:00 盘后），中英文关键词各搜一次，结果写入面板与资产映射；确实无当日数据就写“截至当前暂无当日美股数据”

### 5. 硬数据核对

面板状态为 `ok` 的指标直接引用，不再重复搜索；`warning` 必须额外核验；`stale` 写“沿用最近有效值”并补最新政策核验。当日无新值的项明确写“沿用上次发布值”。

研究时必须核查（不要求正文逐项展示）：Fed 利率区间与下次会议预期、PBOC（LPR/MLF/逆回购/流动性/汇率表态）、BOJ、ECB、美国 10Y/2Y/DXY/非农/CPI/PCE/零售、中国 CPI/PPI/社融/M1M2/PMI/出口、COMEX 与伦敦金/Brent/WTI/USD-CNH。

`DXY` 面板为空或 `warning` 时视为待补位项而非跳过；`Fed / BOJ / ECB` 即使面板有历史利率值，也必须另搜最新会议与政策口径。

## 内容规则

### 读者假设

主要读者是 fixed_tracked 的主 Agent、Bull、Bear、三名独立 Juror 与 finalizer。报告提供共同宏观事实、变化与传导条件，供各角色独立判断；行业景气、公司经营、估值和具体交易动作由股票研究角色自行分析。职责边界以报告契约为准。

今天产出的文件**默认给“明天重新开始的新 AI”读**。它可以读到今天这份文件，但**不会回看昨天或更早的文件**——所以今天文件须独立说明核心状态与传导逻辑，仅保留理解判断必需的最小背景，不承担完整历史档案功能，不得为继承旧稿突破字数上限。

### 写作要求

- 先写“今天和昨天相比变了什么”；无实质新增就沿用昨日框架，但仍要写出当前有效的状态快照
- 按“陌生读者只读今天文件”的标准写：仅对入选的关键事件在首次出现处用一句话交代必要背景
- 持续性事件、版面结构、资产映射与明日关注的具体写法，**统一以 [report_contract.md](references/report_contract.md) 为准**，不要另立标准
- 数据写“公布值 vs 预期值”；官方定调与市场/机构解读分开写；区分已核实事实与推断

### 禁止


- 不写行业研究、个股经营分析或逐股行情名单；只保留足以影响整体风险偏好的市场信息
- 不要把深度研究/搜索长报告原样复制为日更稿；不要逐条记新闻；不要为没新闻的日子硬凑内容
- 不要堆叠持续事件的冗余历史，也不要只剩“升级/僵持”这类结果词
- 不要只写“利多/利空”而不解释传导链条
