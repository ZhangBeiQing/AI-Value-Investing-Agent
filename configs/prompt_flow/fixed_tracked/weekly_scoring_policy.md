# 每周全池轻量评分规则

## 目标与边界

将个股研究转成可比较的五维评分，供全池观察和研究关注。每股一个 Agent 一次完成，不生成交易动作、仓位或目标价。五维各占20%，分数为0—100的整数；分数越高表示该维度对投资条件越有利。综合分由代码等权平均，Agent 不输出 `composite_score`。

## 必须按顺序完成的四步

### 第一步：核对事实与时点，不先给分

完整读研究包§1—§4、`01_global_context.md`和本规则。长文件分段顺序读到末尾，不只看摘要、关键词或旧报告结论。记录分析日、最新原始财报披露日、行情日、预测更新时间和重大事件状态；不输出推理全文，最终理由保留决定分数的事实和数据缺口。

- 数据所属期不等于披露日：半年报统计到6月底，不代表6月底已知报告数字。
- 分析日以后披露的实际财报、价格、复产结果不能用于历史评分；当时已披露的未来计划可以讨论，但写成计划。
- 旧研究的扩产、利润预测和投资结论只作线索。新公告与旧研究冲突，以截至分析日最新可靠披露更新判断，不同时采信互斥说法。
- 一致预期缺少样本和更新时间时，不称“预期上修”，也不假定已包含最新事件，标记时点待核实。
- 关键事实优先公司和交易所披露，同源转载不是独立验证。低可信传闻不能直接触发重大扣分或支撑高分。

### 第二步：逐维判断正面、负面与净影响

每维分别回答：最重要的正面证据是什么？负面证据是什么？哪项影响更大、持续多久、证据是否可靠？不按利好利空条数投票，同一个故事的多篇报道只计一次。

重大事件必须落实到经营变量：哪项业务、规模、恢复或兑现时间、原有未来基准情景是否仍成立。不能量化时说明方向与影响范围，不编造损失、事件概率或复产日期。

区分事实、计算与推断。资料不足不等于公司差，也不等于没有风险；使用接近中性的暂定分并说明缺口，不编造乐观结论，也不一律归零。

### 第三步：先选档，再选整数

宏观、量价、新闻预期、基本面使用统一锚点，估值使用后文八档：

| 分数 | 净判断 | 证据要求 |
| --- | --- | --- |
| 90—100 | 显著有利且兑现可靠 | 多项可核验强证据，主要不利因素已解决，不是单季高增或标签 |
| 75—89 | 明确有利 | 正面影响明显占优，关键假设有兑现证据，重大缺口不改变净判断 |
| 60—74 | 温和有利 | 有具体支持，但重要约束仍在，或兑现尚需验证 |
| 45—59 | 中性、混合或待核实 | 正负接近、净影响不明确或关键资料不足，说明是哪一种 |
| 30—44 | 明确不利 | 可核验负面超过正面，恢复或改善证据不足 |
| 0—29 | 严重不利 | 核心条件显著破坏且未恢复，不是仅因缺数据 |

先判断档位，再选整数。混合结论不默认给70或80。不追求个位数精度，证据支持时才细分相邻分数。

### 第四步：检查分数与理由是否一致

交付前检查：重大负面未解除却给高分，是否有足够抵消证据？是否把涨价、并表、低基数或一次性收益当可持续经营能力？是否采信过期计划、未来披露或机构资金故事？是否把股价跌幅、历史位置或低PE直接等同低估？是否在各维重复奖励或机械重复扣分？

出现矛盾时核实关键事实，或降低判断确定性，不能只在高分理由末尾追加风险。

## 五个维度

### 1. 宏观市场情绪：外部环境对该股的影响

以研究包中的宏观上下文（`01_global_context.md`，含宏观总结与上证指数/大盘状态）为主，必要时联网补充截至分析日的宏观与大势信息，判断当前宏观环境与市场风格对这只股票是顺风还是逆风。行业景气与公司经营问题不属于本维，本维只评“外部环境”。

要分三层并分别说明传导方向：

1. **宏观总量环境**：国内外利率与流动性（海外高利率通常压制高估值科技股的估值、国内低利率与宽松流动性通常利好高股息/红利资产）、汇率与外部约束、大宗商品价格（尤其对上游与周期股的成本与售价）、财政与产业政策、战争与和平。逐项落到本股的需求、融资成本、汇率敞口、商品暴露与政策依赖，说明是正传导、负传导还是中性。

2. **大盘与市场位置**：当前上证/所属指数处于相对高位还是低位（结合点位、趋势与近期涨跌），是增量资金入场还是缩量存量博弈。大盘杀跌、风格切换、成交萎缩通常对高贝塔、高估值成长股更不利，对低估值防御股相对抗跌。指数位置与个股价格位置要分开，不能只凭指数涨跌给个股下结论。

3. **市场风格与资金偏好（重点）**：先判断当前主导风格属于哪一类，再说明它对本股是顺风、逆风还是无关。常见风格有：科技成长 vs 防御红利、大盘权重 vs 中小盘、资源/周期 vs 消费内需、趋势 vs 反转，以及政策/国家队资金的护盘方向（例如科技大幅回调后，资金转向防御型大盘股护盘，会从高贝塔成长股抽走资金）。同一宏观事件对不同风格股票方向可能相反，必须结合本股所处的风格与行业属性判断，不能只看个股自身逻辑。

结论要落到“当前风格（若存在）会不会、以及通过什么路径影响本股的核心逻辑”，给出净判断：顺风、逆风、中性

### 2. 估值：当前PE/PB的历史位置、价格分布与盈利变化

**完整读取研究包 `### 1.2 Valuation Report (Markdown)`，直接使用其中现价、PE/PB、历史序列和价格分布。已有数据就是判断依据，不另设“必须找到可信估值锚”的前置门槛。** 必须完成以下三组对比：

1. **当前PE与历史PE对比**：写明当前扣非TTM PE、历史同口径PE范围/中位水平、当前处于低位/中位/高位。研究包有历史PE百分位时直接使用；只有报告期序列时可给“报告期样本分位”，明确样本数，不能冒充每日PE百分位。不要混用动态PE、TTM PE与前瞻PE，剔除无意义的亏损PE。
2. **当前PB与历史PB对比**：写明当前PB、历史PB范围/中位水平和历史位置；有历史PB百分位就使用。只有报告期样本时同样标注口径。检查净资产、ROE、业务和并表变化是否影响历史可比性，不能因PE与PB结论不一致就停止判断。
3. **历史价格高于/低于现价的占比**：关注两个方向的累计占比。低于现价占比=低于现价的历史交易日数/总交易日数；高于现价占比同理，等于现价单列。只有分箱表时，累加现价所在档以下和以上各档的交易日占比；所在档内部无法拆分，所以分别给上下界，不能把整个所在档任意划到某一侧。
4. **历史高低价格和当前价格背景对比**: 分析历史最高和最低价格时该股票的综合情况，比如宏观、行业、盈利因素多重共振使股票涨到最高和最低，然后把他们的背景和当前背景进行对比，作为估值背景知识补充

随后结合利润增速、盈利持续性、行业景气和已核验的经营变化，解释PE/PB与价格位置为何一致或背离。例如PB低位而PE高位，要核查是否盈利下降导致PE分母缩小，不能把“PB低”直接等同低估。历史价格低位不自动代表便宜，历史高位也不自动代表高估。


**按公司类型解释上述对比：**

- 稳定型：正常盈利、持续现金流、分红及历史可比倍数。
- 周期型：中周期盈利、正常化价格、成本与供需，必要时结合资产或矿山现金流价值。PB是参照而非唯一锚，高商品价不自动证明顶部，低前瞻PE/PEG不自动证明便宜。
- 已验证产业爆发型：行业空间、供需、公司份额与利润兑现支持的未来情景；科技标签、单季高增、股价强不构成分类依据。需验证行业增长、供需错配、公司受益地位、公司经营兑现和可信基准情景，不把多个乐观假设同时当基准。
- 过渡/混合型：规范化利润、分部估值或多情景，不强行套爆发型。

由销量、价格、结构、毛利率、费用、特殊项构建盈利桥。停产、订单变化、扩产推迟必须进入情景，不照搬未更新的一致预期

估值体系分为八档：

| 价格印象 | 分数区间 |
| --- | --- |
| 明显低估 | 90—100 |
| 偏低估 | 78—89 |
| 合理偏低估 | 66—77 |
| 合理 | 54—65 |
| 合理偏贵 | 42—53 |
| 偏贵 | 30—41 |
| 明显高估 | 15—29 |
| 泡沫 | 0—14 |

估值理由必须写：当前PE/PB及财务基准期 → 历史PE/PB对比与分位口径 → 价格高于/低于现价的累计占比或区间 → 盈利变化如何影响这些指标 → 明确价格印象与分数。未提供的精确统计不编造，但不能用泛泛的“估值待核实”代替已有数据分析。

### 3. 量价：趋势、稳定性与可验证筹码

读§1.1，以未来一至三个月为观察窗口。先分别描述短期动量、中期趋势与稳定性，再给综合分。

- 最近两天反弹强，不等于中期趋势健康；结合价格结构、量能连续性与恢复程度，均线/MACD只作辅助。
- 波动、回撤结合自身历史和行业判断，不仅因高波动就认定趋势破坏。
- 单日主力净流入是交易分类统计，不直接等于机构加仓。
- 股东数看同口径变化，不凭绝对值判散户扎堆；持仓披露区别所属期与公开日。
- 质押属于融资治理风险，不替代筹码判断；已发生强平、减持等交易证据才进入量价。

### 4. 新闻与未来预期：新信息怎样改变未来经营

读§2、§3，核查近一个月新闻及重大持续事件，评价下一季度到未来6—12个月的净影响。

- 分开已兑现历史业绩、旧预期、最新变化。发布一个多月的高增长预告不能一直当全新超预期。
- 说明新信息改变了订单、产销量、成本、利润、现金流或资本开支的什么变量，并判断是否已被价格计入。
- 已核验的重大经营中断、客户丢失、许可证问题等尚未解除且足以改变基准情景时，通常不高于50；给更高分须有可靠恢复或其他盈利改善覆盖损失的证据，不仅用行业景气抵消。
- 传闻或小业务扰动不冒充重大破坏。风险已解除时恢复判断，不永久惩罚。
- 开工、计划、试车、达产分别判断，远期储量不记成近期产量；旧报告错了不等于今天发生了新延期。
- 收购不天然利好，评对价、融资、整合与增量回报；评级条数不替代盈利预测变化。

### 5. 基本面：持续经营质量与兑现能力

完整读§3，按行业特性评价，不设统一ROE/毛利率阈值。先分三方面，再综合：

- 资产与竞争力：资源、技术、客户、成本、份额、护城河；资源总量不等于经济可采储量或可变现利润。
- 正常化盈利与现金流：拆分销量、价格、并表、基数与一次性收益；现金流与匹配口径利润比较，不因低于含一次性收益的归母净利就断定恶化。
- 执行、资本配置与治理：生产稳定、项目兑现、维持与扩张投入、债务、管理能力；经营现金流不等于扣除必要投入后的自由现金流。

较强资源或单季利润加速不能直接得到75分以上。高分需同时得到盈利质量、竞争力和兑现能力支持。核心经营能力出现已核验严重问题时，资产优势可保留，但整体高分必须解释可持续兑现路径，不能称“有瑕疵”就带过。

估值评价格，新闻评新变化，基本面评经营韧性。同一事实可涉及多维，但每维回答不同问题，不重复奖励同一涨价故事，也不在所有维度机械扣同一停产风险。

## 搜索、理由与输出

搜索截至分析日可得的最新财报/预告、重大公告、持仓或股东变化、行业供需与价格、持续风险进展。优先解决会改变净判断的关键缺口，不机械增加搜索次数；已有估值表不重复抓取。查不到保留未知，研究包无新闻不代表公司无新闻。

每维理由使用简短证据摘要：`事实/口径：……；正面：……；负面：……；净判断：……；待核实：……`。无明确证据就直说。估值额外写类型、历史PE/PB对比、价格高低占比与基准期。建议每维100—250字，重大事实不因字数删掉。

最终不写URL、Markdown链接、脚注、括号来源引用或独立来源清单。低可信信息确实影响判断时仅标注“低可信来源”或“未经证实”及影响，不写来源名称、标题或链接，不编造数字。

输出继续遵守 `weekly_score.schema.json`：顶层只有 `symbol`、`stock_name`、`scores`、`composite_reason`；`scores`只有 `market_sentiment`、`valuation`、`price_volume`、`news_expectation`、`fundamental` 五组 `_score` 与 `_reason`，共10个键。分数必须为整数。

`composite_reason`说明整体判断、短板、最大风险或催化、关键缺口；不输出综合分。没有全池合并排名，不自称处于全池中位、前列或某百分位。数值高低不等于排名分位。不模仿某只股票的示例分数。

交付前检查四步法、日期、维度边界、风险对判断的影响、分数与理由一致性和JSON格式。固定规则以本文件为准，不依赖其他交易角色定义。
