# 季度基本面报告输出结构

最终文件是完整 Markdown 研究报告，不是 JSON，不包含真实买卖指令。

## 强制结构

```markdown
# 公司名（代码）报告期季度基本面深度研究

## 1. 核心结论
## 2. 公司类型、主要收益来源与本期判断
## 3. 公司业务全景
## 4. 最近两年季度趋势
## 5. 本期财报核心数据
## 6. 分业务、分产品、分区域与子公司
## 7. 利润变化归因
## 8. 毛利率、费用、现金流与资产负债表
## 9. 订单、存货、产能与领先经营指标
## 10. 产业链空间、供需、利润节点与公司地位
## 11. 财报前预期、实际结果与预期差
## 12. 财报前计价程度与财报后估值
## 13. 下一季度与未来六至十二个月推演
## 14. 全年一致预期完成要求与预测修正
## 15. 程浩然天花板估值及适用限制
## 16. 风险、替代解释与证伪条件
## 17. 下一季度验证清单
```

可根据公司业务合并不适用小节或增加必要小节，但不得省略重大问题。

`draft_v1.md` 等过程稿允许追加“未解决问题与披露限制”和“证据与来源”，供
Challenger 与 Author 修订时使用。最终 `financial_reports/YYYYMMDD.md` 禁止保留
这两个独立章节：

- 真正影响判断但公开信息无法解决的事项，按性质融入 §16 或 §17；
- 来源贴近对应事实、数字和判断标注，不单独堆砌来源清单；
- 不输出质询处理过程、修订日志或研究过程附录。

## 产业链研究必须全量转写

§10、§15 不是结论摘要，必须把 `research_outputs/industry_chain_research.md` 的核心研究内容**完整转写**进最终报告，禁止压缩成一句话带过。至少覆盖以下子节（有则全量，无则说明缺项）：

**§10 产业链空间、供需、利润节点与公司地位** 必须包含：

1. **链条验证**：`terminal_theme → subchain → value_chain_node → company_exposure` 逐层写明，并说明候选行业标签与公司实际业务暴露是否成立、公司与行业链条的边界（哪些节点不属于本链）；
2. **终端需求与 TAM**：需求单位与当前规模、三至五年终局空间公式、三情景（Bear/Base/Bull）的招标或市场空间、增长来源分解（渗透率/单位价值/国产替代/短期价格各占多少）；
3. **供需与利润映射（分节点表）**：每个价值量节点（如换流变、换流阀、GIS/开关、电抗器、配套、海外出口）的需求驱动、供给约束、当前状态、利润流向、公司对该节点的暴露——逐行写，不得合并；
4. **当前供需状态**：在建/投产节奏、供给约束与集中度、全球短缺与出口溢出、原材料价格及其对公司毛利的影响、行业利润扩散是否已确认；
5. **公司暴露与竞争地位**：主题收入占比（注明公司是否单列披露）、分部主题毛利与利润（收入故事 vs 利润故事要分别标注）、竞争地位优势与短板（换流阀/GIS 等分节点对比竞争对手中标额与份额）、客户集中度与议价约束；
6. **竞争对手与替代技术**：主要竞争对手（名称+各自中标额/份额/毛利率），柔性直流/GIL/SST 等替代技术对环节利润分配的影响；
7. **下一期领先指标** 与 **证伪条件**：完整列出，不得省略。

**§15 程浩然天花板估值及适用限制** 必须包含：

1. **适用前提**：公司类型（如 mixed）为何决定必须按分部估算，哪些远期故事（换流阀/SST/海外）不能折算成整体利润，能否拆出主题纯利润；
2. **天花板三情景**：悲观/基准/乐观各自的利润、估值倍数、理论市值，并注明是"情景上限非目标价"；
3. **当前市值在天花板中的位置**：市值落在哪个区间、隐含了哪种"利润+估值"组合；
4. **联合发生约束**：Bull 情景同时押注哪些假设、各假设是否有季度兑现证据、联合概率为何低于单项概率；
5. **适用限制与反例**：什么情况下天花板不适用、与 Base 合理中枢的差距。

> 若某个子节在 `industry_chain_research.md` 中确实不存在或属不可得数据，需写明"该子节未覆盖/无法验证"，不得用行业故事填补。

## 核心表格

报告应在数据可得时包含：

- 最近两年分季度核心指标表；
- 重大分部趋势表；
- 财报前预期差矩阵；
- 未来驱动因素或情景表；
- 财报前与财报后估值口径表。

不存在高可信季度一致预期时，不伪造“实际 vs 季度一致预期”数字列；改为年度锚、公司指引、产业隐含预期和计价判断。

## 写作规则

- 首段直接说明本期最重要的变化，不先铺陈行业常识。
- 每个重大数字写明期间、单位、同比/环比和来源。
- 推导值写公式，未知值写未知。
- 区分事实、计算、管理层解释、Agent 推断和反面证据。
- 不限制每节条目数量或全文字数；以完整回答重大问题为准。
- 不输出 recommended_action、action_num、price_target、stop_loss 或仓位建议。

## 发布前质量门禁

- 重大数字已核对且单位一致；
- 估值财务基准期已标明；
- 财报前预期没有时间穿越；
- 年度预期没有冒充季度预期；
- 新财报口径 TTM/Forward 估值已重算或说明无法计算；
- 公司整体与主要业务已有趋势和归因；
- §10 已完整转写产业链研究（分节点供需表、TAM 与三情景、增长来源分解、公司暴露、竞争对手、领先指标与证伪条件），不是一句话摘要；
- §15 已完整转写天花板情景与适用限制（三情景、市值位置、联合发生约束）；
- 产业研究已经落到公司利润暴露；
- Challenger 的高严重度问题已修正，或已按影响融入 §16/§17；
- 最终报告没有“未解决问题与披露限制”或“证据与来源”独立章节；
- 没有占位符、伪造来源或真实交易指令。
