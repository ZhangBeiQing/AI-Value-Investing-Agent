# 季度全面基本面研究规则

## 一、研究目标

最终报告必须回答：

- 过去两年公司整体与主要业务如何变化；
- 为什么变化，主要原因和次要原因是什么；
- 变化属于一次性、周期性还是结构性；
- 经营质量和资产负债表是否支持利润；
- 本期财报验证、削弱或证伪了哪些既有假设；
- 下一季度和未来六至十二个月由什么驱动；
- 什么可观测事实可以确认或证伪推演。

不得只复述管理层叙事，也不得为了完整而虚构未披露的分部数字。

## 二、阅读顺序与历史记忆

Financial Author 第一遍只读本期财报、上期原始财报和当期结构化上下文，先形成独立事实判断。

完成第一遍后，才读取 `prior_fundamental_memory.md`，检查：

- 上期假设是否兑现；
- 管理层指引是否兑现；
- 上期未解决问题是否有新答案。

旧估值结论、交易动作和目标价不得进入基本面记忆。

### 按需回溯历史财报原文

正常研究以 workdir 中的最新财报、上一期关键财报和本地结构化数据为主。不要预设每次必须读取过去固定 N 年的全部财报，也不要为了“更全面”批量加载历史文件。只有出现以下明确缺口时才回溯：

- 无法补足最近两年季度趋势所需的可比报告期；
- 同比基期、季节性或累计值拆单季度缺少原始口径；
- 分部、会计政策或统计口径发生变化，需要找到变更前披露；
- 异常利润、减值、投资收益、现金流、应收、存货、订单或资本开支需要追溯形成过程；
- 需要核验管理层过去的正式指引、承诺或长期项目进度；
- Challenger 提出了会实质改变结论、且只能从历史原文回答的问题；
- 强周期、重大并购重组或业务转型使两年窗口明显不足。

历史原文目录由 `05_agent_input.md` 声明，严格按以下顺序只读检索：

1. 先检查 workdir 已提供的 `01_latest_report.md` 和 `02_previous_report.md`，避免重复读取同一报告；
2. 再到 `disclosures/md/` 用文件名、报告期和关键词定位 Markdown 原文，优先使用 Markdown，因为可以用 `find` 和 `rg` 快速定位相关章节；
3. 只有目标报告没有 Markdown 时，才到 `disclosures/pdfs/` 按文件名和报告期定位 PDF 原文，只读取解决当前缺口所需的报告和相关页；
4. 不批量读取整个目录，不批量把 PDF 转成 Markdown，不因本轮研究自动调用 MinerU；
5. PDF 无文本层、表格无法可靠提取或目标报告不存在时，把问题保留为数据缺口并说明影响，不猜测数字。

同一报告的 Markdown 转换稿和 PDF 原文属于同一个来源，不能算独立交叉验证。Expectation Scout 使用历史披露时仍必须遵守财报公告前时间边界；任何角色都不得因为目录中存在未来文件而越过本次研究截止时间。

## 三、财务趋势

公司整体至少覆盖：

- 营业收入；
- 归母净利润；
- 扣非归母净利润；
- 毛利率与核心分部毛利率；
- 销售、管理、研发和财务费用率；
- 经营现金流、自由现金流与资本开支；
- 应收、存货、合同负债、预付款、在建工程和有息负债；
- 非经常损益、投资收益、汇兑、减值、补助和税率。

尽可能建立最近两年分季度表，同时给出同比、环比和季节性解释。累计值推导单季度时标记为“推导值”；无法推导时说明披露限制。

## 四、分业务研究

对每个重大业务、产品、区域或子公司回答：

```text
发生了什么
→ 绝对额、同比、环比和占比
→ 主要与次要原因
→ 原因的大致贡献
→ 暂时、周期还是结构
→ 对下一期的传导
→ 验证指标
```

如果公司合并披露、改变口径或把重要业务放入“其他”，必须列为披露缺口，并尝试通过子公司、订单、销量、价格、同行和产业数据侧面验证。

## 五、经营质量与反事实

至少检查以下背离：

- 收入增长与应收增长；
- 利润增长与经营现金流；
- 订单增长与合同负债；
- 扩产与产能利用率；
- 存货与收入/价格；
- 公司叙事与同行、客户、供应商数据；
- 净利润与扣非净利润；
- 资本化投入与费用化投入。

管理层解释若为真，应说明哪些其他指标应同步变化；未同步时构造替代解释。

## 六、未来推演

预测必须由业务驱动因素组成：

```text
收入 = 销量 × 单价 + 产品结构 + 新业务
毛利 = 各业务收入 × 各业务毛利率
经营利润 = 毛利 - 期间费用
自由现金流 = 经营现金流 - 资本开支
```

区分：

- 公司正式指引；
- 正式机构一致预期；
- Agent 的证据推演。

按 `company_valuation_framework.md` 的公司类型选择驱动因素。场景假设必须可观察和可证伪，不能只做线性外推。

## 七、事实、推断与未知

- 事实：标明报告期、披露日期、单位和来源。
- 计算：列公式和输入，注明是否为推导值。
- 推断：说明证据链和替代解释。
- 未知：明确数据缺口及其对结论的影响。

来源冲突时保留冲突，解释选择依据；不得悄悄选择更符合原结论的数据。

## 八、研究闭环

基本面事实不投票。流程是：

```text
Author 初稿
→ Challenger 提问、补搜和压力测试
→ Author 逐项回应并修订
→ 高严重度问题解决或明确列为未解决
```

Challenger 必须产生新问题或新证据，不重复总结初稿。
