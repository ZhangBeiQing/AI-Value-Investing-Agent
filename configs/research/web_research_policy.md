# 联网搜索与证据规则

## 一、强制搜索入口

所有外部搜索必须首先使用阿里云百炼的语义搜索能力：

```text
bailian_web_search
```

工具前缀可能因 Codex、OpenCode 或 MCP 配置不同而变化，应按能力名称发现，不把某个完整内部工具名写死。

如果该能力不存在或服务传输失败：

- 记录 `search_status = bailian_unavailable`；
- 停止依赖外部搜索的角色；
- 不静默切换其他搜索引擎；
- 只有用户明确允许 fallback 后才使用替代搜索。

"搜索成功但无结果""只有低等级来源"和"工具不可用"必须区分。

## 二、搜索与原文阅读分工

```text
百炼搜索
→ 发现候选来源和后续检索关键词

打开具体网页或 PDF
→ 核对选中的公司公告、交易所文件、协会数据、正式研报或原始页面
```

百炼的召回顺序、来源数量和摘要语气都不代表可信度。搜索摘要只能用于发现线索，不能单独支持财务数字、订单、客户、产能、正式指引、关键预期或交易结论。

搜索应围绕明确问题，并尽量加入来源锚点，例如公司名称、证券代码、公告类型、投资者关系、交易所或目标机构。宽泛搜索只用于发现线索；发现线索后必须继续追溯原始来源。

## 三、来源分级与证据准入

### 3.1 来源等级

按以下顺序选择来源：

1. **A 级：** 公司公告、财报、交易所和监管文件；
2. **B 级：** 公司业绩会、投资者关系记录、政府、行业协会，以及客户、供应商和竞争对手的正式披露；
3. **C 级：** 正式卖方研报、持牌财经媒体的独立采访或调查；
4. **D 级：** 百家号、其他身份不明的自媒体、内容农场、聚合转载和无法识别原始出处的内容。

### 3.2 特殊来源：雪球、股吧等投资社区

雪球、股吧、投资者论坛等投资社区不按普通 D 级来源处理，因为它们有独特的双重属性：

**有价值的一面：** 这些平台上确实经常有行业内人士、从业人员和各行各业的大佬出没，有时会出现提前爆料、产业一线观察、对官方信息的专业解读等，能够提供宝贵的线索和不同于机构研报的视角。机构研报虽然等级更高，但中国机构很多报喜不报忧，可信度也未必绝对可靠。

**有风险的一面：** 同时充斥着大量情绪化言论、庄托、谣言和利益相关方的刻意引导。

因此采用独立的处理规则：

**第一步：尝试交叉验证。**
发现有价值的线索后，先用其他独立来源验证——通过联网搜索寻找是否有 A/B/C 级来源支持或否定同一说法。

**第二步：如果找到独立验证，正常采信。**
通过至少两个独立的高等级来源（A/B 级）或三个相互独立的 C 级来源验证后，信息可以进入事实和结论，并注明原始线索来源和验证链路。

**第三步：如果找不到独立验证，按以下规则分级处理。**

很多情况下雪球上的信息确实是独家的、提前的、无法从任何正式渠道找到验证的——比如业内人士在财报前透露产能数据、工厂员工发帖说产线状态、供应链人员爆料订单变化等。这些信息后续常常被事实证明是正确的，但因为找不到独立验证就完全丢弃，会错过重要的领先信号。

因此，当雪球/股吧上的信息无法找到 A/B/C 级独立来源验证时，**不机械按未知处理**，而是根据信息本身的质量分两档：

**可用的未验证信号（可以作为决策参考，但不能作为唯一依据）：**

- 信息具体、有时间/地点/数字等可核查的细节（不是"业绩不错""行业很好"这种模糊说法）
- 发帖人有可追溯的历史发言记录，且历史记录显示其对该行业/公司有一定了解
- 信息涉及的是客观事实层面（产能、订单、价格），而不是主观判断层面（目标价、估值高低）
- 信息逻辑自洽，不与已知的 A/B 级事实冲突

符合以上特征的未验证信息，可以：
- 作为辅助信号进入分析，但必须明确标注"未经验证，仅为雪球/股吧线索"
- 用来调整对一只股票的信心程度——比如原本只想建 2% 试探仓，如果有一个高质量的未验证正面信号，可以建 3%；或者原本想重仓，提示有一个未验证负面信号，可以等验证后再加
- 用来质疑机构一致预期、识别潜在风险、或形成"需要重点跟踪什么"的观察清单
- **不能**作为交易决策的唯一理由或主要依据——不能因为一条未验证的雪球帖子就直接重仓买入或恐慌卖出

**不可用的信号（丢弃）：**

- 信息模糊，缺乏可核查的具体细节
- 纯情绪化、口号式、或明显利益导向的言论
- 发帖人历史记录不可追溯或明显是水军/营销号
- 与已知的 A/B 级事实明显矛盾
- 涉及主观价值判断（"严重低估""必然翻倍"）而非客观事实

对于不可用的信号，按噪声处理，不进入任何分析。

### 3.3 百家号

百家号是百度自媒体平台，内容质量普遍极低，常见入口包括 `baijiahao.baidu.com`、`mbd.baidu.com` 及标注"百家号"的百度作者页面。

- 百家号**只能提供搜索关键词灵感**，不能进入任何事实、预测、估值假设或交易结论。
- 不得因为标题中出现公司名、证券代码或精确数字而提高其证据等级。
- 如果搜索结果只有百家号内容，视为"无可靠来源"，按未知处理。

### 3.4 通用证据准入规则

**核心原则：任何重要结论都不能只依赖单一来源，必须经过交叉验证。**

- 重大事实和关键结论应有至少一个 A/B 级来源。
- A/B 级来源确实不存在时，可以使用两个相互独立的 C 级来源，并明确说明证据降级和不确定性。
- 即便使用了 A/B 级来源，也应在条件允许时搜索是否有其他独立来源支持或反驳同一结论——单一来源永远不如多源交叉验证可靠。尤其注意机构研报可能存在报喜不报忧的倾向，能用公司公告、交易所文件或第三方独立数据交叉验证的，就不要只依赖研报。
- 多个网站转载同一篇文章、同一匿名爆料或同一搜索摘要，不算相互独立的来源。
- 搜索结果中只有雪球/股吧的未验证信息时，按 3.2 节的分级规则处理——高质量未验证信号可以保留并标注，低质量的丢弃。搜索结果只有百家号或其他纯 D 级来源时，按未知处理。
- 不得用低质量内容填补证据空白。
- 来源等级只解决可信度，不代替时效检查；即使是 A/B 级来源，也要核对发布日期和适用期间。

## 四、证据最小信息

每条重大证据记录：

- 事实或原始数字；
- `period_end`；
- `release_date`，可得时记录时间；
- `fetched_at`；
- 来源标题与 URL；
- 来源类型；
- 口径、单位和可信度；
- 它支持或反驳哪个结论。

历史复盘按 `release_date` 判断当时可见性，不按 `period_end`。

若角色输出契约没有独立证据字段，就把必要的日期、来源名称、来源等级和结论影响写进对应的理由或正文，不得擅自增加 JSON 字段。

## 五、搜索循环

围绕当前知识缺口构造搜索，而不是机械执行固定问题列表：

```text
提出缺口
→ 百炼召回
→ 按 3.1~3.3 分级处理来源（雪球/股吧按 3.2 分级评估，百家号按 3.3 仅保留关键词）
→ 追溯并选择高等级来源
→ 打开原文核对
→ 搜索是否有独立来源支持或反驳同一结论
→ 更新结论
→ 检查是否出现新冲突或缺口
```

当重大问题仍缺证据时继续搜索；当公开信息确实没有答案时，明确写未知及影响，不得用低质量内容填空。
