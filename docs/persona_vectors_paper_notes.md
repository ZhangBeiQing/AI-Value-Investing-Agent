# Persona Vectors 论文笔记：为什么 “evil vector” 不是纯净的邪恶旋钮

> 论文：**Persona Vectors: Monitoring and Controlling Character Traits in Language Models**  
> arXiv: [2507.21509](https://arxiv.org/abs/2507.21509)  
> 记录日期：2026-07-23

## 一句话结论

论文中的 `evil vector` 更适合理解成：**从一批“邪恶回答”和“非邪恶回答”的内部激活差异中提取出的、与邪恶行为高度相关的粗粒度方向**，而不是神经网络中天然存在、只负责“邪恶”且与其他功能完全正交的单一开关。

因此，沿着这个方向干预模型时，改变的可能不只是恶意意图，还可能连带改变不礼貌、冷漠、夸张、幽默、幻觉倾向，以及模型偏离默认“有帮助、诚实、无害”助手风格的程度。

## “不同人格方向彼此相关”具体是什么意思

这里至少包含三个层次，不能混为一谈。

### 1. 几何相关：向量方向不正交

作者计算了不同 persona vector 之间的余弦相似度。部分负面人格方向，以及 `humorous`，存在明显的非零相似度；`optimistic` 往往朝相反方向。

如果两个单位向量完全正交，余弦相似度为 0，沿其中一个方向移动，理论上不会在另一个方向上产生投影。若：

```text
cos(v_evil, v_impolite) > 0
```

那么给隐藏状态加入 `evil vector` 时，也会自动加入一部分在 `impolite vector` 上的分量。换句话说，这两个实验提取出的方向共享了一些神经表示。

这并不表示两个概念完全相同。论文也发现，用某个人格自己的向量预测该人格，通常仍然比使用其他人格向量更准确，说明它们既有重叠，也保留了一定特异性。

### 2. 行为共变：一次微调会让多个特征一起漂移

论文观察到，模型用某类数据微调后，不一定只改变一个人格分数。`evil`、`sycophancy`、`hallucination`、`impolite`、`apathetic` 和 `humorous` 等分数可能一起上升或下降，而 `optimistic` 可能反向变化。

这叫“共变”或“共同漂移”：它说明这些测量指标对同一次模型变化有相似反应，但**单凭共变不能证明其中一个特征导致了另一个特征**。

例如，下面几种解释都可能产生共同漂移：

- 模型内部确实有一个较宽泛的共同机制，例如“偏离默认助手人格”。
- 微调数据同时包含恶意、不礼貌、夸张、虚构等多种属性。
- 提取向量的方法没有把内容、语气和道德倾向充分解耦。
- 自动评分器对这些表面特征存在交叉敏感性。

论文展示了这种相关现象，但没有最终确定唯一的因果机制。

### 3. 数据相关：差分提取会把共同出现的属性一起装进向量

论文大致通过以下方式提取人格向量：

1. 准备一组表现目标人格和不表现目标人格的对比 system prompt。
2. 让模型对同一批问题分别生成两类回答。
3. 提取回答 token 在某一层的 residual-stream 激活并求平均。
4. 用“目标人格回答的平均激活”减去“对照回答的平均激活”。

可写成：

```text
v_evil = mean(h | evil responses) - mean(h | non-evil responses)
```

问题在于，自然语言里的“邪恶回答”通常不会只比对照回答多出一个抽象的邪恶概念。它还可能更具攻击性、更冷酷、更极端、更戏剧化，甚至包含黑色幽默或有害技术内容。因此，差分向量会把这些在数据中共同出现的属性一起吸收。

可以用一个仅供直觉理解、并非论文真实分解结果的表达式表示：

```text
v_evil ≈ 恶意意图
       + 攻击性语言
       + 冷漠/不礼貌
       + 极端或戏剧化表达
       + 偏离默认助手风格
       + 数据与评分噪声
```

论文附录中的 SAE 分析也支持“粗粒度混合方向”这一理解：与 evil vector 对齐的特征包括侮辱和虐待性语言、蓄意残酷，以及恶意代码或黑客内容等，而不是一个单一、原子化的“邪恶神经元”。

## 为什么连 humor 也会一起漂移

这不意味着“幽默等于邪恶”。更合理的解释是，论文中提取到的 `humorous vector` 与若干负面人格方向共享了某些表示成分，例如：

- 不严肃、夸张、戏剧化或反常规的语言风格；
- 与标准、克制、积极的默认助手口吻相反；
- 构造人格数据时，讽刺、黑色幽默、冒犯性笑话与负面内容共同出现；
- 评分器可能把机智的虚构、夸张或自信表达与部分其他人格指标混淆。

所以，最稳妥的结论是：**当前方法提取到的向量存在共享成分**。它还不足以证明模型内部有一个统一的“邪恶—幽默模块”。

## 论文究竟是怎么“注入人格”的

主要控制实验使用的是 activation steering，而不是先做拒绝向量消融：

```text
h_l <- h_l + alpha * v_trait
```

即在模型生成的每一步，把目标人格向量按强度 `alpha` 加到选定层的隐藏状态中。若要压制某种人格，则使用负方向：

```text
h_l <- h_l - alpha * v_trait
```

system prompt 的主要作用包括：

- 生成正、负人格对照回答，用于提取向量；
- 直接诱发人格变化，再测试 persona vector 能否监测这种变化；
- 作为部分实验条件或比较基线。

论文**没有先移除 refusal vector，再注入 evil vector**。作者还指出，所测试的 Qwen 和 Llama 模型面对 evil system prompt 时拒绝率很低，所以能够直接采集相应回答。更强安全对齐模型如果大量拒绝，这套数据构造方法可能需要调整。

“evil vector 可能混入拒绝倾向”是值得验证的研究假设，但不是这篇论文已经证明的结论。要验证它，需要另外提取 refusal vector，测量余弦相似度，并通过正交化和因果干预进行比较。

## 注入 evil 后，模型的很多能力都会下降吗

这篇论文**没有给出“注入邪恶人格会普遍降低代码、常识、数学等多种能力”的充分证据**。

需要区分几个实验方向：

- 论文用错误数学答案、问题代码、医学建议和主观意见等数据做微调，观察人格是否发生意外漂移。这是在问“某类微调数据是否让人格变坏”。
- 这不等于先注入 evil，再证明数学或代码能力因此下降。
- 论文主要使用 MMLU 检查一般能力保持情况，而不是系统地覆盖 HumanEval、GSM8K、MATH、常识等完整能力矩阵。
- 作者发现，推理时用很强的反向 steering 压制人格会损害 MMLU；这说明过强的隐藏状态干预可能扰乱通用计算，但不能直接推出“邪恶本身导致能力下降”。
- 预防式 steering 在微调过程中通常能更好地减少人格漂移并保持 MMLU，说明干预方式和强度非常重要。

因此，严谨表述应是：

> Persona vector 可以因果性地改变目标行为，但向量不完全纯净，过强干预可能影响通用能力。论文尚未证明 evil 人格本身会让代码、数学、常识等能力全面下降。

## 论文已经支持与尚未支持的结论

### 已有证据支持

- 多种 persona vector 在几何上存在非零相关，而不是两两正交。
- 微调后，不同人格指标可能出现共同漂移。
- 每个人格自己的向量通常仍是该人格最好的预测方向，说明向量并非完全相同。
- 沿 persona vector 做 activation steering，可以因果性改变对应行为。
- 提取出的方向是粗粒度的，可能同时编码语义内容、表达风格和行为倾向。
- 干预过强可能破坏通用能力。

### 论文没有证明

- 模型内部存在一个纯净、独立、唯一的“邪恶模块”。
- humor 在道德或机制上等于 evil。
- 所有共同漂移都由同一个主轴造成。
- evil 注入会让代码、数学、常识等所有能力普遍下降。
- 作者在实验前移除了 refusal vector。
- evil vector 已被证明包含 refusal vector；这仍需专门实验。

## 如果要把问题研究得更干净，可以怎样设计实验

1. **做向量正交化**：从 evil vector 中依次去除 sycophancy、hallucination、humor、refusal 等方向的投影，再比较人格效果与能力变化。
2. **控制对比数据**：让正、负样本在长度、语气、幽默程度、礼貌程度、事实性和拒绝率上严格匹配，只改变恶意意图。
3. **做二维因子实验**：分别控制“是否拒绝消融”和“是否注入 evil”，形成 2×2 条件，判断两者是否交互。
4. **比较三种干预**：system prompt、activation steering、权重微调分别测试，并匹配实际人格强度，而不只匹配 steering 系数。
5. **建立完整能力矩阵**：同时评估代码、数学、常识、事实性、校准、长上下文和安全拒绝，报告各项随人格强度变化的曲线。
6. **使用多个独立评分器**：结合人工盲评，检查人格共同漂移是否部分来自 judge bias。
7. **跨模型复现**：在强拒绝模型和弱拒绝模型上分别实验，检验所谓共同方向是否只是特定对齐方式的产物。

## 最容易误读的地方

“向量相关”不等于“概念相同”；“行为一起变化”不等于“一个行为导致另一个行为”；“强 steering 损害能力”也不等于“邪恶导致智能下降”。

这篇论文真正重要的启示是：**模型人格可以被内部方向监测和操控，但当前 persona vector 更像统计上有效的复合控制方向，而不是已经被成功解剖出的单一心理变量。**
