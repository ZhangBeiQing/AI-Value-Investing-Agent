# 每日研究输入与裁决流程优化

更新日期：2026-11-09。

## 输入分层契约

Step Name: financial_daily_brief_selection（01–04）。

Input: 按既有可见性窗口选定的完整 `financial_reports/YYYYMMDD.md`，及可选同名 `.daily.json`。

Output: 原有 `04_stock_research/*.md`，财报部分优先使用有效摘要。

Side Effects: 不改完整报告，不更新交易账本，不生成05；研究缓存版本为5。

Validation: 摘要身份、原文哈希、知识日期、篇幅、结构与引用检查；失效回退及每日预测保留测试；临时目录单股实际生成。

Compatibility Notes: 原报告、01–05和最终决策字段保留。非每日财报调用继续读取全文。

摘要由原 Financial Author 在全文核对完成后生成，无需新增 Agent；目标 3000–5000 非空白字符，允许表达完整时更短。
完整产业、历史趋势及远期情景保存在深研档案。日常摘要保留公司盈利逻辑、关键计算、反面证据、风险及验证条件。
缺失、原文修订导致哈希失效、身份不匹配、知识日期越界或结构不合格时，明确回退全文，不截断。
旧报告未补摘要前仍消耗全文输入，不能宣称已经全池压缩。新研究注册增加 --require-daily-brief。准备脚本的 daily_brief_items 会列出已完成深研但缺有效摘要的报告，仅补摘要、不重做深研。

## 当前裁决契约

Step Name: independent_stock_adjudication（04→05）。

Input: 当日共同规则、宏观、单股研究包、两份独立 opening，以及实际持仓上下文。

Output: 单一 `final/stock_verdict.json`，可选定向质询/解决记录；人工确认后合并为05。

Side Effects: 不自动真实交易，不改变现金、仓位、价格引用或最小交易单位规则。

Validation: 角色文件完整、质询闭环、决策字段、动作/持仓语义、卖出数量与现有交易单位；组合现金仍复核，执行器保留资金检查。

常规两方研究→独立裁决，3角色3turn。决定性争议才要求定向回应，不机械增加重复角色。
模型更强不保证判断正确，同模型三次判断也不代表三次独立证据；重点是关键事实核验和反面证据。

## 验证与实际交易

保留 P0 确认、组合复核、05生成确认和真实交易后处理单独授权。不同市场明确价格日期与币种，
不能把待成交卖出收入默认当作可用现金。现有策略没有硬性仓位上限，本次未新增上限或止损线。

程序测试只证明契约，不证明收益。评估研究质量应固定同一时点输入，比较决定性事实错误、重大遗漏、动作/数量差异、
实际 token/费用/耗时；覆盖平静日、新财报、重大负面事件和分母变化，不用未来资料证明历史判断正确。
