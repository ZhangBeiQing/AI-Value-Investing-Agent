## 本文件的定位

本文件只保留一个最小索引，供仓库内的人类开发者快速定位相关 skill 资源。

它不再承担：

1. AI 执行说明
2. 主题字段契约说明
3. 事件链筛选规则说明
4. 渐进式总结工作流说明

这些内容统一收敛到 skill 自带的 `references/` 目录中维护。

## 当前唯一有效流程

当前唯一有效流程是：

1. 生成今日 `03_news_prompt_input.json`
2. 读取最近一天 `06_hot_news_state.json`
3. 读取最近一天宏观总结
4. 读取最近一天板块热点状态
5. 由 `gradual-hot-news-summary` skill 生成新的 `06_hot_news_state.json`
