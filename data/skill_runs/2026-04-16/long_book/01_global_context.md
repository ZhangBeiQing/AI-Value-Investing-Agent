## 3. 央行与流动性

### Fed

- 事实：`2026-04-16` 发布的 Fed 褐皮书显示，大部分辖区经济仍温和增长，但全部 `12` 个辖区能源和燃料成本都明显上升，中东冲突被明确列为企业招聘、定价和资本开支决策的不确定性来源。
- 事实：市场主流预期仍指向 `4 月会议按兵不动`，并未因为风险偏好修复而重回快速降息叙事。
- 推断：Fed 现在最重要的约束不是增长失速，而是 `油价和战争不确定性抬高通胀黏性`。只要这条线不消退，美债长端就不容易趋势性下行，高估值成长也只能结构性走强。

### PBOC

- 事实：人民银行 `2026-04-16` 公开市场开展 `5 亿元` `7 天期逆回购`，操作利率 `1.40%`，当日等量到期，实际为 `零投放零回笼`。

- 推断：PBOC 仍是 `稳汇率 + 精细化对冲 + 给结构转型腾空间`。这对银行、高股息、制造龙头并不构成破坏，同时也允许 AI、通信、高端制造继续交易业绩和政策方向。

### BOJ

- 事实：公开新闻口径显示，日本市场对 `4 月` BOJ 加息预期有所降温，核心原因仍是油价和中东风险让政策前景更复杂。
- 事实：如果能源价格维持高位，日本面临的输入型通胀约束并未消失。
- 推断：BOJ 当前更像被动等待，而不是给全球风险资产提供明确宽松锚。亚洲成长的改善更多来自中国结构性数据，而不是日本政策宽松。

### ECB

- 事实：公开信息显示，ECB 方向依旧强调若能源冲击推升通胀，中短期政策路径可能比此前市场想象更偏鹰。
- 事实：这意味着欧洲仍处于 `增长承压 + 通胀扰动未退` 的两难环境。
- 推断：ECB 不能给全球成长股提供稳定宽松背景，因此港股和 A 股成长更应理解为 `中国自身结构改善`，而不是外部流动性全面转暖。

## 6. 持续性风险跟踪

### 6.1 中东 / 美国-伊朗 / 霍尔木兹

- 最小背景：这条线决定油价、黄金、航运、全球通胀预期以及 Fed/ECB/BOJ 的政策上限，因此仍是所有风险资产估值的共同约束。
- 关键节点链：
  - `2026-02-28`：美国与以色列对伊朗动手，地区冲突升级。
  - `2026-04-08`：美伊宣布临时停火，市场从极端供给冲击后撤一步。
  - `2026-04-14`：美国对伊朗港口封锁进入执行阶段，风险从纯军事冲突转向 `封锁 + 谈判` 双线博弈。
  - `2026-04-16`：市场继续交易协议希望，但封锁和对伊朗运输体系的约束并未明确解除。
- 最近几天最新进展：公开新闻显示，特朗普继续释放“短期内达成协议”的乐观信号，但同一天市场并未把原油和黄金完全打下来，说明交易员仍然认为通航、制裁和执行层面的不确定性存在。
- 当前状态判断：`尾部风险下限有所抬升，但供给扰动和能源溢价没有退出。` 这不是全面升级，但也绝不是完全消化。
- 资产与政策传导链：`谈判预期抬升 -> 成长股风险偏好修复 -> 但油价和黄金维持高位 -> 通胀黏性与央行观望继续 -> 全球高估值资产上限仍被约束。`

### 6.2 中国增长结构 / 新质生产力 / 地产拖累

- 最小背景：中国当前不是简单的“总量弱”，而是 `制造、科技投资、出口链更强，地产和传统消费更弱`。这直接决定 A 股和港股的主线分布。
- 关键节点链：
  - `2026-03` 两会延续稳增长与转型并重框架，没有重新打开地产总刺激。
  - `2026-04-13` 前后金融与信用数据表明总量不差，但结构更偏稳增长托底。
  - `2026-04-16` 一季度 GDP 与 `3 月` 经济数据落地，验证经济开局尚可，但地产链继续承压。
- 最近几天最新进展：一季度 GDP 同比 `+5.0%`，工业增加值同比 `+5.7%`；与此同时，`1-3 月` 房地产开发投资 `-11.2%`、销售面积 `-10.4%`、到位资金 `-17.3%`，说明地产并未从拖累变成支撑。
- 当前状态判断：`中国总量稳、风格偏成长和高端制造`。这解释了为什么今天更该看重算力、通信、电池、半导体设备，而不是把地产链当成反转主线。
- 资产与政策传导链：`GDP 和工业数据稳 -> 创业板/港股科技/高端制造风险偏好修复 -> 地产与传统消费仍弱 -> 总量宽松预期不上修 -> 高股息保留底盘，成长走结构行情。`

### 6.3 全球央行观望约束

- 最小背景：Fed、ECB、BOJ 面临的共同难题不是需求过热，而是 `战争和能源价格让它们无法放心转向宽松`。
- 关键节点链：
  - `2026-04` 上旬：中东冲突与封锁冲击油价和航运预期。
  - `2026-04-16`：Fed 褐皮书把中东冲突写成不确定性来源，ECB/BOJ 口径也继续被能源风险牵制。
- 最近几天最新进展：Fed 明确看到能源成本抬升，欧洲方向继续担心通胀再抬头，日本方向则因地缘与油价扰动压低政策可预测性。
- 当前状态判断：`全球央行短期内更像延长观察，而不是同步宽松。`
- 资产与政策传导链：只要油价和黄金仍处高位，利率和美元就不容易出现趋势性下行，全球成长资产可以反弹，但估值上限仍受限。
