- 相比 `2026-04-01`，最大变化是特朗普在 `4月1日` 晚间讲话中不再强调“很快收兵”，而是明确表示未来 `2-3 周` 会继续加大对伊朗打击力度，并提到伊朗能源设施也可能成为目标。AP 同日还确认，伊朗继续对以色列和部分海湾邻国发射导弹，霍尔木兹海峡受阻状态并未解除。

- 美国宏观这边，昨天发布的 `3 月 ISM 制造业 PMI 52.7` 强于前期扩张读数，`4 月1日` 发布的 ADP 私营就业 `+6.2 万` 则显示就业没塌、但也不热。真正决定 Fed `4 月 28-29 日` 会前定价的，还是 `4 月3日` 的美国 `3 月非农`。

## 3. 央行与流动性

### Fed

- 事实：Fed 在 `2026-03-18` 维持联邦基金利率目标区间 `3.50%-3.75%` 不变，并明确表示会关注中东局势对美国经济的影响；下次会议在 `2026-04-28` 至 `2026-04-29`，`4 月8 日` 先看 `3 月` 会议纪要。
- 市场预期：`4 月` 继续按兵不动仍是主流；但如果油价维持在 `100+`，即便就业走弱，Fed 也不容易快速转鸽。
- 资产映射：现在 Fed 交易核心不是“增长会不会马上塌”，而是“油价会不会把通胀二次抬起来”；这对长久期美股和黄金节奏都不友好。

### PBOC

- 事实：本地面板仍显示 `2026-03-20` LPR 持平，`1Y 3.0% / 5Y 3.5%`；今天没有新的降息或大宽松信号，人民币仍是“稳中略弱”。
- 市场预期：短期更可能继续靠公开市场操作和结构工具稳流动性，而不是立刻大幅降息。
- 资产映射：A 股主线仍偏 `高股息 + 央国企 + 资源 + 制造业修复`，而不是地产链全面反转。

### BOJ

- 事实：BOJ 在 `2026-03-19` 以 `8-1` 维持无担保隔夜拆借利率在 `0.75%` 左右不变，并在声明中明确提示要关注中东紧张与油价上涨；下次会议在 `2026-04-27` 至 `2026-04-28`。
- 市场预期：在油价继续抬升时，BOJ 很难完全忽视输入性通胀，但短线更像“继续观察”，不是立刻再加息。
- 资产映射：若能源继续贵，日元与亚洲套息交易波动都可能加大，港股和日股高弹性板块会更颠簸。

### ECB

- 事实：ECB 在 `2026-03-19` 维持主要再融资利率 `2.15%`、存款便利利率 `2.00%`、边际贷款利率 `2.40%` 不变；同时把 `2026` 年通胀预测抬到 `2.6%`、增长预测下调到 `0.9%`，明确把中东战争视为近端通胀上行、增长下行来源。下次会议时间为 `2026-04-30`。
- 市场预期：欧洲现在不是“能不能宽松”，而是“高油价会把宽松再往后推多久”。
- 资产映射：ECB 越难放松，全球长端利率越难顺畅下行，港股和欧美成长股估值修复越容易被打断。

## 6. 持续性风险跟踪

### 6.1 中东 / 美国-以色列-伊朗 / 霍尔木兹

- 最小背景：这条主线决定全球油价、航运、通胀和主要央行路径。核心不是单纯“有没有导弹”，而是霍尔木兹海峡和海湾能源设施能否恢复正常运输。只要运输与装运没有实质恢复，全球资产就会继续按“能源供给受限”定价。
- 关键节点链：
  - `2026-02-28`：美以对伊朗开战，风险从区域摩擦升级为地区级战争。
  - `2026-03 中旬`：打击从军事目标延伸到能源与基础设施，霍尔木兹进入持续受阻状态，市场开始按“真实供给缺口”交易。
  - `2026-03-26`：特朗普曾把针对伊朗能源设施的打击暂停到 `4 月6 日`，市场一度押注“有谈判窗口”。
  - `2026-04-01` 至 `2026-04-02`：特朗普改口转强硬，称未来 `2-3 周` 将继续重击伊朗；AP 同时确认伊朗仍在向以色列和部分海湾国家发射导弹，英国 `4 月2 日` 召集约 `35` 国讨论未来如何重开霍尔木兹。
- 最近几天最新进展：
  - 最近 `24 小时` 不是停火落地，而是“停火口风破功”。特朗普没有给出可信的立即收兵路径，反而把军事强度表述继续抬高。
  - 伊朗方面也没有展现“已经停止施压海峡”的迹象；相反，导弹袭击仍在继续，霍尔木兹依旧是现实瓶颈而不是抽象威胁。
  - 国际社会开始讨论“战后如何重开海峡”，本身就说明各方默认海峡问题并未解决。
- 当前状态判断：`高位僵持重新偏向升级`。今天和昨天的区别不在于背景变了，而在于市场重新意识到“昨天那种快速降温叙事并不牢靠”。
- 资产与政策传导链：`霍尔木兹受阻 / 海湾设施风险 -> Brent/WTI 再冲高 -> 输入性通胀预期抬升 -> Fed/ECB/BOJ 更难转鸽 -> 美债与美元回升 -> 黄金短线受利率和美元压制但中期避险逻辑未死 -> 美股长久期板块与港股成长承压，油气/航运/军工继续占优`。

### 6.2 俄乌 / 黑海停火框架

- 最小背景：俄乌仍通过欧洲能源、粮食和军费链条影响全球宏观，尤其影响欧洲增长与 ECB 的操作空间。
- 关键节点链：
  - `2022` 冲突爆发后，欧洲能源与军工支出长期进入资产定价。
  - `2026-03 中下旬`：美国分别与俄乌推动黑海和能源设施停火框架，市场一度交易局部降温。
  - 随后双方继续互相指责对方破坏设施，停火框架未转化为稳固执行。
- 最近几天最新进展：最近几天没有新的突破性停火进展。
- 当前状态判断：`继续僵持，边际影响弱于中东`。
- 资产与政策传导链：它仍压制欧洲制造修复和 ECB 放松空间，但不是今天全球市场最强的边际驱动。

### 6.3 中美贸易 / 出口管制 / 制造业调查

- 最小背景：这条线决定中国出口制造、港股科技估值和全球制造业资本开支预期。
- 关键节点链：
  - `2025-10` 双方曾有短暂关税休战，但出口管制和产业调查没有退出。
  - `2026-03-12` 特朗普政府重启针对制造业、铜和钢铁的调查。
  - `2026-03-15` 中美官员在巴黎会谈，为 `5 月中旬` 北京峰会做准备。
  - `2026-03-27` 中国对部分美企启动调查，双方继续保留谈判筹码。
- 最近几天最新进展：最近几天没有新的大规模加税落地，说明博弈还停留在“调查与试探”阶段。
- 当前状态判断：`峰会窗口仍在，但政策不确定性没有解除`。
- 资产与政策传导链：若后续升级为实质新关税或更严出口管制，港股科技、半导体和中国出口链会先受压；若 `5 月` 峰会前维持克制，港股互联网与出海制造仍有修复空间。

### 6.4 中国地产 / 地方债

- 最小背景：中国地产和地方债是国内信用周期的总约束，决定 A 股是不是能从“结构行情”升级为“全面风险偏好回升”。
- 关键节点链：
  - `2024-2025` 去库存、保交楼、地方债置换持续推进，但没有回到旧地产周期。
  - `2026-03-05` 两会继续强调稳增长和防风险，没有给地产再开总闸。
  - `2026-03-20` LPR 持平，说明货币端仍偏稳汇率和稳信用。
  - `2026-03-31` PMI 回升，说明非地产部门先修复，但地产仍未成为拉动项。
- 最近几天最新进展：最近几天没有新的超强刺激政策。
- 当前状态判断：`弱修复、未出清`。
- 资产与政策传导链：这也是为什么 A 股内部更偏银行、央企、高股息和制造龙头，而不是全面回到地产贝塔。

## 7. 资产映射

- **A股**：短线更像 `资源 + 能源链 + 高股息 + 军工 + 制造修复` 的组合；若油价继续高位，航空、纯消费和部分中下游成本敏感板块会更难受。
- **港股**：港股同时受 `美元/利率` 与 `中东风险` 压制，科技成长的反弹窗口仍在，但必须建立在油价别继续失控上冲的前提上。
- **黄金**：今天下跌更像“强美元 + 强油价 + 强利率”的战术回撤，不是中期逻辑反转；若战事继续升级，黄金仍可能重新获得避险买盘。
- **石油**：石油仍是第一宏观锚。只要霍尔木兹没有实质恢复通行，油价中枢就很难明显回落。
- **美股**：美股最怕的是“油价高位 + ISM偏强 + Fed更久不动”的组合，指数层面容易反复，能源、防务、现金流稳定板块相对占优。
