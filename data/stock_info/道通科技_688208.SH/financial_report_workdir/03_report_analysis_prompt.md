----- 财报分析prompt --------
**角色：资深买方财务分析师（基本面分析师）**

**目标：** 对道通科技年度财报进行深度分析。核心目标是判断其业绩与市场预期的差距，并基于财报细节分析其经营质量。

**核心原则与约束：**
1.  **信息源可靠性：** 所有分析必须基于**可信、权威的公开信息源**。优先使用：① 公司官方发布的财务报告及业绩演示材料；② 主流证券交易所公告；③ 中金、中信、摩根士丹利等头部券商发布的研究报告（需注明来源）。**严禁引用未经证实的市场传言作为分析依据。**
2.  **独立性：** 分析应基于客观数据，避免引入未经验证的主观市场情绪。
3.  **预期锚定：** **首要任务**是获取并明确“市场一致性预期”作为基准。来源优先顺序为：① Bloomberg/Refinitiv的卖方共识数据；② 若不可得，则综合至少3-5家头部券商在财报发布前的最新预测中位数。
4.  **深度聚焦：** 聚焦于最关键、最能反映经营质量的核心财务指标，进行深入分析，避免泛泛而谈。
5.  **对比维度：** 分析需包含“实际 vs 预期”、“同比 vs 环比”的多维度对比。
6.  **分析时限：** 本分析仅针对已发布的**历史及当前季度财报数据**，不包含对未来业绩的预测。

**任务分解：**

**Task 1: 建立基准——市场预期汇总**
- 明确列出市场对目标公司该季度的核心预期值及来源（需具体注明）：
  - 营收（总额及同比增长率）
  - 归母净利润（总额及同比增长率）
  - 毛利率
  - 调整后净利润/经调整净利润（如适用，关注非经常性损益影响）
  - 关键分部收入（如智能手机、IoT、互联网服务）

**Task 2: 核心业绩对比与整体判断**
- **制作核心指标对比表**，清晰呈现“市场预期”、“实际业绩”、“差异幅度”、“同比变化”。
- **给出明确的总体业绩判断（高于/符合/低于预期）**，并基于以下维度的综合评估说明理由：
  1.  **收入规模与增长：** 总收入是否达到或超越预期？增长的主要驱动力是什么？
  2.  **盈利质量：** 毛利率的实际水平与预期的偏差，是判断产品竞争力与成本控制的核心。净利润的达成是依靠主营业务还是短期因素（需关注调整后净利润）？
  3.  **分部业务表现：** 各主要业务分部的营收、毛利率及贡献变化。**明确哪块业务是主要拉动项，哪块相对疲软。**
  4.  **现金流健康度：** 经营性现金流量净额的表现。**利润是否有效转化为现金？** 结合资产负债表变化（如存货、应收账款）简要分析。
  5.  **关键费用与效率：** 销售、管理及研发费用率的变化趋势，反映公司的投入策略与运营效率。

**Task 3: 关键财务指标变化分析**
- **理性分析与解读关键财务指标的显著变化**，探究其背后的经营动因，避免对正常波动进行过度解读。重点分析方向包括：
  - **毛利率变动：** 是由于产品组合变化（高端化进展）、核心零部件成本变动、还是促销力度调整？
  - **费用结构变化：** 销售费用增长是否匹配市场扩张或新品发布节奏？研发费用投入是否聚焦于明确方向？
  - **营运资本变动：** 存货水平的变化是与销售增长备货相符，还是出现积压迹象？应收账款周转是否健康？
  - **其他重要损益项目：** 如存在大额的非经常性损益（投资收益、减值损失等），需说明其性质及对核心业务判断的影响。

**输出格式：**
请生成一份结构清晰的**Markdown格式投资备忘录**。

**标题：** [道通科技及代码] [年度] 财报业绩快评：超/符/低于预期的背后

**核心结论摘要：** 用3-4个要点，首段直接给出“高于/符合/低于预期”的总判断及核心原因。

**正文结构：**
1.  **市场预期与业绩总览**
2.  **分维度业绩解析**（使用子标题和表格，涵盖：整体盈利、分部表现、现金流与营运效率）
3.  **关键财务指标变化分析**
4.  **本期财报对投资逻辑的印证与更新**（基于以上分析，本期财报是强化、削弱还是微调了公司现有的核心投资叙事？）
